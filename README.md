# OptiMetrics AI — Адаптивна підготовка та оптимізація медіаконтенту

Науково-дослідний програмний комплекс для інтелектуального профілювання, форензичного аудиту та адаптивного кодування цифрових зображень на основі об'єктивних метрик якості та психофізичних моделей зорового сприйняття (HVS).

---

## Інструкція щодо використання веб-додатку

1. **Завантаження та первинний вхід:**
   * Перетягніть файл у форматі JPEG, PNG або WebP у вікно або виберіть один із попередньо підготовлених контрольних зразків:
     - **Фотографічне зображення:** еталонне фото для оцінки збалансованого квантування.
     - **Векторна графіка:** контрастний контент для тестування субдискретизації 4:4:4 без втрат.
     - **Зашумлене зображення:** зразок з адитивним гаусовим шумом для тестування білатеральної фільтрації.
2. **Діагностичне профілювання:**
   * Система автоматично формує вектор метрик (рівень шуму за двома алгоритмами, просторова складність SI, ентропія Шеннона, різкість за Лапласом, субдискретизація кольору та гістограми).
3. **Форензична діагностика та мікроскопічна лупа:**
   * У блоці форензики доступні 11 аналітичних режимів (ELA, шум, градієнт яскравості, PCA, зріз бітових площин LSB, детекція клонів тощо).
   * При наведенні курсору на зображення активується **Pixel Magnifier (Лупа)** зі збільшенням 8×, точними координатами пікселя (X, Y), значеннями HEX/RGB та локальною RGB-гістограмою.
4. **Автоматичний синтез рішень або ручне керування:**
   * У блоці **«Модуль автоматичного синтезу рішень»** виводиться точне числове обґрунтування та таблиця порогових критеріїв, на базі яких синтезовано стратегію.
   * Для проведення експериментів доступний **ручний режим** з вибором кодеків: WebP, JPEG, PNG, а також кафедральних кодеків BPG ($Q \in [1\dots51]$), AGU ($QS$) та ADCT ($QS$).
5. **Оцінка стиснення та експорт звіту:**
   * За допомогою інтерактивного Split-слайдера візуально зіставте оригінал та оптимізоване зображення.
   * Натисніть **«Експорт наукового звіту (JSON)»** для збереження всіх числових метрик, порогових правил і показників SSIM/PSNR/CR у файл звіту.

## Матриця числових критеріїв та порогових значень автоматичних рішень

Рішення формуються на основі детермінованих числових інтервалів:

| Параметр і формула | Числовий поріг | Класифікація контенту | Прийняте системне рішення |
|---|---|---|---|
| **Ентропія Шеннона ($H$)**<br/>$H = -\sum p(i)\log_2 p(i)$ | $H \ge 7.00$ біт/пікс<br/>$5.00 \le H < 7.00$<br/>$H < 5.00$ біт/пікс | **$H \ge 7.00$:** Висока ентропійна щільність.<br/>**5.00–6.99:** Помірна (типове фото).<br/>**$< 5.00$:** Низька (однотонні зони, UI). | Визначає щільність градацій яскравості. У поєднанні з просторовою інформацією $SI$ формує інтегральний індекс $C_{score}$. |
| **Просторова інформація ($SI$)**<br/>$SI = \text{std}(\sqrt{S_x^2 + S_y^2})$<br/>*(ITU-T P.910)* | $SI \ge 45.0$<br/>$20.0 \le SI < 45.0$<br/>$SI < 20.0$ | **$SI \ge 45.0$:** Висока контурна активність.<br/>**20.0–44.9:** Помірна динаміка.<br/>**$< 20.0$:** Гладкі градієнти, розмиті фони. | Визначає наявність високочастотних деталей. Високий $SI$ активує зорове просторове маскування шуму квантування. |
| **Інтегральна складність ($C$)**<br/>$C = \min(100, \frac{H}{8}\cdot45 + \min(55, SI\cdot0.85))$ | $C \ge 70.0$<br/>$C < 35.0$<br/>$35.0 \le C < 70.0$ | **$C \ge 70.0$:** Висока просторова складність.<br/>**$C < 35.0$:** Низька складність / Плавні переходи.<br/>**35.0–69.9:** Збалансований сюжет. | **$C \ge 70.0 \rightarrow Q = 80$:** За правилом маскування HVS шум квантування в текстурах непомітний для ока; досягається високе стиснення.<br/>**$C < 35.0 \rightarrow Q = 88\dots90$:** Захист градієнтів від артефактів ступінчастості (color banding).<br/>**35.0–69.9 $\rightarrow Q = 84$:** Еталонна якість. |
| **Оцінка шуму ($N_{score}$)**<br/>$\sigma_{imm}$ (Immerkaer) + $\sigma_{don}$ (Donoho MAD) | $Score > 40.0$ ($\sigma > 8.0$)<br/>$20.0 < Score \le 40.0$<br/>$Score \le 20.0$ ($\sigma \le 4.0$) | **$> 40.0$:** Критичний високочастотний шум.<br/>**20.1–40.0:** Помірний шум сенсора.<br/>**$\le 20.0$:** Чистий сигнал (шум у нормі). | **$> 40.0$:** Активація двовимірної білатеральної фільтрації ($d=7, \sigma_r=40, \sigma_s=40$). Запобігає марній витраті до 50% бітрейту на шум!<br/>**20.1–40.0:** М'який білатеральний фільтр ($d=5, \sigma_r=22$).<br/>**$\le 20.0$:** Фільтрацію вимкнено (деталі 1:1). |
| **Субдискретизація колірності**<br/>*(Chroma Subsampling)* | Графіка ($D_{col} < 0.08, H < 6.8$)<br/>Фотографічний сюжет | **Графіка / UI / Текст:** Контрастні межі.<br/>**Фото:** Неперервні півтони. | **Графіка $\rightarrow$ 4:4:4 або Lossless:** Запобігає розмиттю колірних меж тексту (chroma bleeding).<br/>**Фото $\rightarrow$ 4:2:0:** Скорочує байти колірних каналів Cb/Cr на 50% без помітних оку втрат. |
| **Різкість (Лапласіан)**<br/>$\text{Var}(\Delta I)$ | $\text{Var} \ge 80.0$<br/>$\text{Var} < 80.0$ | **$\ge 80.0$:** Різке зображення.<br/>**$< 80.0$:** Розмите / нефокусоване. | Фіксується у звіті; для нефокусованих зображень усувається перевитрата бітрейту на відсутні деталі. |

## Математичні моделі та алгоритми

1. **Оцінка рівня адитивного шуму (Noise Estimation):**
   * **Алгоритм Й. Іммеркаєра (J. Immerkaer Fast Noise Estimation, 1996):** Лапласіаноподібне $3\times3$ ядро для оцінки дисперсії адитивного гаусового шуму без попередньої сегментації:
     $$\sigma = \frac{\sum |I * N_{mask}| \cdot \sqrt{\pi / 2}}{6 \cdot (W - 2) \cdot (H - 2)}$$
   * **Вейвлет-метод Донохо (Donoho Haar Wavelet MAD):** Оцінка на базі медіанного абсолютного відхилення коефіцієнтів піддіапазону $HH_1$:
     $$\hat{\sigma} = \frac{\text{median}(|HH_1|)}{0.6745}$$
2. **Просторова складність (Spatial Information, SI, ITU-T P.910):**
   $$SI = \text{std}\left(\sqrt{S_x^2 + S_y^2}\right)$$
3. **Теорія інформації (Shannon Entropy):**
   $$H = -\sum_{i=0}^{255} p_i \log_2(p_i)$$
4. **Оцінка фокусу та різкості (Focus Measure):**
   Дисперсія оператора Лапласа $\text{Var}(\nabla^2 I)$.
5. **Аналіз колірної субдискретизації (Chroma Subsampling):**
   Парсинг маркерів заголовків JPEG (SOF0/SOF2) для визначення схеми (4:4:4, 4:2:2, 4:2:0) та інспекція ICC-профілів.
6. **Криміналістична лабораторія та інспектор артефактів (Forensics Studio):**
   * **Error Level Analysis (ELA):** виявлення ділянок з різними рівнями стиснення.
   * **Noise Analysis:** карта залишкового шуму сенсора.
   * **Luminance Gradient:** перепади освітленості у палітрі Viridis.
   * **Level Sweep:** покрокове сканування ізоліній квантування (постерізація).
   * **Principal Component Analysis (PCA):** декомпозиція 3D колірного простору.
   * **Edge Detection:** багатомасштабний контурний аналіз Canny.
   * **Histogram Equalization (CLAHE):** виявлення прихованої інформації в тінях.
   * **Channel Isolation:** ізоляція каналів (R, G, B, Y, Cb, Cr).
   * **Bit-Plane (LSB):** поплощинний аналіз молодших бітів (стеганографія).
   * **Clone Detection:** автоматичний пошук клонованих фрагментів (штамп).
   * **Мікроскопічна лупа (Magnifier):** інтерактивна лупа 8× з точними координатами (X, Y), HEX/RGB та живою локальною RGB-гістограмою.
7. **Об'єктивна валідація якості:**
   * **SSIM (Structural Similarity Index)** — структурна подібність.
   * **PSNR (Peak Signal-to-Noise Ratio)** — пікове відношення сигнал/шум у дБ.
   * **CR (Compression Ratio)** — коефіцієнт стиснення та відсоток економії пам'яті.

## Запуск проєкту

### 1. Бекенд (Python + FastAPI)

```bash
cd backend
# Активація віртуального оточення
.\venv\Scripts\activate
# Запуск сервера
uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

API доступне за адресою: `http://127.0.0.1:8000` (Документація Swagger: `http://127.0.0.1:8000/docs`)

### 2. Фронтенд (React + Vite)

```bash
cd frontend
npm run dev
```

Веб-інтерфейс відкривається за адресою: `http://127.0.0.1:5173`
