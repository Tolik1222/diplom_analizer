# Математичні моделі та алгоритми

1. **Оцінка рівня адитивного шуму (Noise Estimation):**
   * **Алгоритм Й. Іммеркаєра (J. Immerkaer Fast Noise Estimation, 1996):** Використовує лапласіаноподібне 3x3 ядро для оцінки дисперсії шуму без потреби в попередній сегментації.
   * **Вейвлет-метод Донохо (Donoho Haar Wavelet MAD):** Оцінка на базі медіанного абсолютного відхилення (MAD) коефіцієнтів високочастотного піддіапазону $HH_1$:
     $$\hat{\sigma} = \frac{\text{median}(|HH_1|)}{0.6745}$$
2. **Просторова складність (Spatial Information, SI):**
   * Стандарт **ITU-T P.910** на базі градієнтів Собеля:
     $$SI = \text{std}\left(\sqrt{S_x^2 + S_y^2}\right)$$
3. **Теорія інформації (Shannon Entropy):**
   * Оцінка інформаційної ємності яскравості в бітах на піксель:
     $$H = -\sum_{i=0}^{255} p_i \log_2(p_i)$$
4. **Оцінка фокусу та різкості (Focus Measure):**
   * Дисперсія оператора Лапласа $\text{Var}(\nabla^2 I)$ та детекція розмитості (blur).
5. **Аналіз колірної субдискретизації (Chroma Subsampling):**
   * Парсинг маркерів заголовків JPEG (SOF0/SOF2) для визначення схеми (4:4:4, 4:2:2, 4:2:0) та інспекція ICC-профілів.
6. **Криміналістична лабораторія та інспектор артефактів (Forensics Studio):**
   * **Error Level Analysis (ELA):** виявлення ділянок з різними рівнями стиснення та склеєних областей.
   * **Noise Analysis:** виділення та контрастування карти високочастотного залишкового шуму сенсора.
   * **Luminance Gradient:** векторні перепади освітленості та тіней у палітрі Viridis.
   * **Level Sweep:** покрокове сканування ізоліній квантування для виявлення постерізації.
   * **Principal Component Analysis (PCA):** декомпозиція 3D колірного простору на некорельовані головні осі.
   * **Edge Detection:** багатомасштабний контурний аналіз Canny.
   * **Histogram Equalization (CLAHE):** виявлення прихованої інформації у глибоких тінях та світлах.
   * **Channel Isolation:** ізоляція колірних каналів (R, G, B, Luma Y, Cb, Cr).
   * **Bit-Plane (LSB):** поплощинний аналіз молодших бітів (біт 0 LSB) для детекції цифрових водяних знаків та стеганографії.
   * **Clone Detection:** автоматичний пошук клонованих/дубльованих фрагментів зображення (ретуш штампом).
   * **Мікроскопічна лупа (Magnifier):** інтерактивна лупа зі збільшенням 2×, 4×, 8×, 16×, точними значеннями пікселя (#HEX, RGB), позицією (X, Y) та живою локальною RGB-гістограмою.
7. **Двигун адаптивних рішень (Adaptive Decision Engine):**
   * Автоматичне визначення цільового формату (WebP / AVIF / JPEG), параметра якості $Q$, активація двосторонньої фільтрації контурів (Bilateral Filter) для зашумлених зображень, збереження 4:4:4 для векторної графіки/UI.
8. **Об'єктивна валідація якості (Quality Metrics):**
   * **SSIM (Structural Similarity Index)** — збереження структурної схожості.
   * **PSNR (Peak Signal-to-Noise Ratio)** — пікове співвідношення сигнал/шум у dB.


## Запуск проєкту

### 1. Бекенд (Python + FastAPI)

cd backend
# Активація віртуального оточення
.\venv\Scripts\activate
# Запуск сервера
uvicorn app.main:app --reload --host 127.0.0.1 --port 8000

API доступне за адресою: `http://127.0.0.1:8000` (Документація Swagger: `http://127.0.0.1:8000/docs`)

### 2. Фронтенд (React + Vite)

cd frontend
npm run dev

Веб-інтерфейс відкривається за адресою: `http://127.0.0.1:5173`
